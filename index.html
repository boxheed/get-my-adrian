What actually is Adrian?

An Automated workflow using Github, Dependabot, CircleCI, n8n, Google Gemini and Google Jules

Google Jules

An asynchronous AI agent designed to act as a fully autonomous developer

Reality

  • Complex API interaction
  • Agent struggled with reliably coordinating the interaction
  • Data is well structured
  • Deterministic behavior

The Flow

Dependabot updates dependencies -> CircleCI builds the new software -> On failure CircleCI triggers n8n workflow -> Workflow gathers data from CircleCI & GitHub -> Prompt generated by n8n -> Google Jules prompted to fix codebase -> writes code changes -> Human reviews and merges

The Prompt

  • Sets the persona
  • Sets out the objective
  • Defines what the agent should not do
  • Provides details about the source code
  • Provides the error log
  • Specifies what has changed
